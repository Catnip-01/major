# Model Files

Place the following files here before building the Docker image or mounting the volume:

- `transaction_model.pkl` — Trained LogisticRegression classifier
- `vectorizer.pkl` — TF-IDF vectorizer (max_features=50000, ngram_range=(1,2))

These are generated by `train2.ipynb` (Google Colab).

## How to get them

1. Open `train2.ipynb` in Google Colab
2. Run all cells — models are saved automatically
3. Download `transaction_model.pkl` and `vectorizer.pkl` via Cell 9
4. Place both files in this directory
5. On EC2: `docker cp transaction_model.pkl palfin-worker:/app/models/`
           `docker cp vectorizer.pkl palfin-worker:/app/models/`

## Fallback behaviour

If models are missing, the classifier falls back to labelling all transactions as "Other".
The app will still work — categories just won't be meaningful until models are loaded.
